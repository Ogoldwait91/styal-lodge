# Styal Lodge — website

A ready-to-run project. You do NOT need to be a coder to preview it.

## Run it on your computer (first time)
1. Install Node.js (the "LTS" version) from https://nodejs.org — run the installer.
2. Install VS Code from https://code.visualstudio.com
3. In VS Code: File > Open Folder… and choose this "Styal Lodge" folder.
4. Open the terminal: Terminal > New Terminal.
5. Type:  npm install   then press Enter. Wait for it to finish (one time only).
6. Type:  npm run dev    then press Enter.
7. Hold Cmd (Mac) or Ctrl (Windows) and click the http://localhost:4321 link.

To stop the preview: click the terminal and press Ctrl + C.
To start it again later: just do steps 6–7.

## The three pages
